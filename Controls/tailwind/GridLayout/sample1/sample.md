## Sample 1: Responsive columns

The `Columns` property sets the number of columns (1 to 12) on the smallest screens. The responsive properties `ColumnsZero`, `ColumnsXXS`, `ColumnsXS`, `ColumnsSS`, `ColumnsSM`, `ColumnsMD`, `ColumnsLG`, `ColumnsXL`, `ColumnsXL2`, `ColumnsXL3`, and `ColumnsXL4` set the number of columns from the corresponding breakpoint up. Breakpoints which are not set inherit the value from the nearest smaller breakpoint.

The `Gap` property sets the spacing between the cells.
