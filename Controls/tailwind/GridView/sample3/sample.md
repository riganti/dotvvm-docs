## Sample 3: Inline editing with Tailwind columns

The Tailwind columns render Tailwind controls in the edit mode: `GridViewDateColumn` and `GridViewDateTimeColumn` use the `DateTimePicker`, `GridViewCheckBoxColumn` uses the Tailwind `CheckBox`, and `GridViewMultiSelectColumn` lets the user pick multiple enum values.

The edit mode is controlled using the `RowEditOptions` of the data set, in the same way as in the built-in [GridView](~/controls/builtin/GridView).

> The `GridViewDateColumn`, `GridViewDateTimeColumn`, `GridViewCheckBoxColumn`, and `GridViewMultiSelectColumn` columns are new in DotVVM 5.1.
