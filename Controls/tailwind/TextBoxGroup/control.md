A composed input area where a text box shares one border with optional content placed above (`StartTemplate`) and below it (`EndTemplate`) - similar to the prompt input in AI chat applications. The whole group looks like a single input.

Use the `TextBoxGroupButton`, `TextBoxGroupComboBox`, `TextBoxGroupDropDownButton`, and `TextBoxGroupLiteral` controls inside the templates - they accept the same properties as `Button`, `ComboBox`, `DropDownButton`, and a plain text, but they are styled to fit in the group.

> The `TextBoxGroup` control is new in DotVVM 5.1.
