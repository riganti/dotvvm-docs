## Sample 2: Prompt input with actions

Use `StartTemplate` and `EndTemplate` to compose a richer input. In this sample, the `EndTemplate` contains a `TextBoxGroupDropDownButton` with additional actions, a `TextBoxGroupLiteral` with a `TextBoxGroupComboBox` for selecting a model, and a `TextBoxGroupButton` which submits the prompt.

The `StartTemplate` can show additional information above the text box, for example the list of attached files using the [UploadedFilesPreview](~/controls/tailwind/UploadedFilesPreview) control.
