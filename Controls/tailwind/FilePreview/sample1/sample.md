## Sample 1: Image and file previews

Use the `FileName` property to specify the name of the file, and `Url` to point to a location from which the image can be loaded. Both properties support data-binding.

If you need to preview files uploaded by the [FileUpload](~/controls/tailwind/FileUpload) control, use the [UploadedFilesPreview](~/controls/tailwind/UploadedFilesPreview) control.
