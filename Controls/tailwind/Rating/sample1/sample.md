## Sample 1: Read-only rating

When `Value` is a hard-coded value, the control only displays the rating. Use `MaxStars` to change the number of icons, `Legend` to show the numeric value or the percentage next to the icons, and `Size`, `Color`, and `ColorShade` to change the appearance.

The `Icon` and `IconType` properties let you use any Heroicon instead of the default star.
