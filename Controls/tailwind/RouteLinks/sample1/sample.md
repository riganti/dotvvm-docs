# Route Link Types

The `RouteLink` component supports different button types for various visual styles:

- **Default**: Neutral link
- **Primary**: Primary action link
- **Secondary**: Secondary/less-emphasized link
- **Success**: Positive/confirm action
- **Warning**: Cautionary action
- **Danger**: Destructive action
- **Info**: Informational link
- **Ghost**: Low-emphasis / transparent
- **Link**: Inline link-styled

Each type applies a different visual appearance while maintaining the same routing functionality.
