Renders an animated placeholder shaped like a list of items. Each row contains an optional circle for an icon or avatar, and two text lines.

See also [SkeletonCard](~/controls/tailwind/SkeletonCard), [SkeletonParagraph](~/controls/tailwind/SkeletonParagraph), and [SkeletonTable](~/controls/tailwind/SkeletonTable).

> The `SkeletonList` control is new in DotVVM 5.1.
