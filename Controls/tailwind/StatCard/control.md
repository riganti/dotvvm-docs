Displays a key metric - a value with an optional label, icon, change indicator, description, progress bar or ring, and a badge. Only the parts which are set are rendered. The `Layout` property selects how the parts are arranged.

To display several cards in one container, use [StatGroupedCard](~/controls/tailwind/StatGroupedCard). To show how a total is split into parts, use [StatSegmentsCard](~/controls/tailwind/StatSegmentsCard).

> The `StatCard` control is new in DotVVM 5.1.
