Renders an animated placeholder shaped like a data table with a header row and data rows. Display it instead of a [GridView](~/controls/tailwind/GridView) while the data is loading.

See also [SkeletonCard](~/controls/tailwind/SkeletonCard), [SkeletonList](~/controls/tailwind/SkeletonList), and [SkeletonParagraph](~/controls/tailwind/SkeletonParagraph).

> The `SkeletonTable` control is new in DotVVM 5.1.
