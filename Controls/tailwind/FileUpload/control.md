Uploads files using a styled drop zone. The user can click the zone to browse for files, or drag and drop files on it. Uploaded files appear in a list with upload progress, errors, and buttons to remove them.

The control works with the `UploadedFilesCollection` class in the same way as the built-in [FileUpload](~/controls/builtin/FileUpload) - see its documentation to learn how to configure the upload storage and how to work with the uploaded files.

> The `FileUpload` control is new in DotVVM 5.1.
