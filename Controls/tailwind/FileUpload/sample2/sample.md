## Sample 2: Compact mode and custom texts

Set `Compact` to `true` to render a single-row drop zone which fits well in forms. The `Enabled` property disables browsing, dropping, and removing files.

All texts can be customized: `Placeholder`, `HintText`, `BrowseButtonText`, `RemoveButtonText`, `FileTooLargeText` (use `{0}` for the size limit), `FileTypeNotAllowedText`, `UploadErrorText`, and `FilesSelectedText` (use `{0}` for the number of files). When the texts are not set, localized default texts are used.
