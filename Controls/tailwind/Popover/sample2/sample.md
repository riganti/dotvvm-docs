## Sample 2: Hover popover and appearance

Set `TriggerType="Hover"` to open the popover when the mouse enters the trigger. The `Delay` property (in milliseconds) postpones opening and closing, so the user can move the mouse into the panel.

Use `Color` to change the panel color, `MaxWidth` to set the maximum width of the panel (any CSS length), and `Offset` to change the gap between the trigger and the panel in pixels. The `Enabled` property can prevent the popover from opening.
