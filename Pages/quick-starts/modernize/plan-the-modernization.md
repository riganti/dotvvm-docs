# Plan the modernization

You can find more information about modernizing .NET web applications in a book [Modernizing .NET Web Applications](https://www.modernizationbook.com) by Tomas Herceg. 

The first three chapters of the book explain the differences between .NET Framework and the new versions of .NET, and show practical examples of how to plan the entire modernization process. 

One of the book's chapters is dedicated to DotVVM and shows the process of migrating ASP.NET Web Forms applications to the latest version of .NET.
